# HR-Attrition-ML-Project

## 📌 Project Overview
This project is a Machine Learning solution for predicting **employee attrition (whether an employee will leave the company or not)**.  
It also includes a **Streamlit dashboard** for interactive predictions.

---

## 🎯 Objective
To analyze employee data and build a model that can predict attrition based on different features like salary, job role, experience, etc.

---

## 📊 Features
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering
- Machine Learning model training
- Attrition prediction system
- Interactive Streamlit web app

---

## 🧠 Machine Learning Models Used
- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier

---

## 🛠️ Tech Stack
- Python 🐍
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Streamlit
